# Todo 1.7.0

保留桌面上的暗金任务树，同时让日常输入、任务查找和数据保存更可靠。

## 新增

- 应用更名为 Todo，恢复原有紫底对勾标识；继续使用原有数据与配置目录。

- 纸白、松绿主题；背景不透明度、任务字号和紧凑视图。
- 完成度、待办 / 紧急 / 完成数量概览。
- 名称搜索、到期与紧急筛选。
- 双击编辑名称与日期；行末可操作菜单和键盘焦点提示。
- 独立桌面演示模式与浏览器内存预览。
- 连续编辑的串行保存队列、保存状态、冲突提示和另存副本。
- 每个文件保留最近 20 份自动备份。
- 自动化数据、保存流程与桌面回退测试；GitHub Actions 检查及手动 Windows 打包。

## 修复

- 跨分区子任务无法导出、重启后丢失的问题。
- 超过五层的任务树被压平，及长列表编号失效的问题。
- 打开文件即重写、读取失败返回示例数据、保存失败仍无反馈的问题。
- 窗口配置覆盖分区高度的问题。
- 外部文件变化触发整页重载、打断输入的问题。
- 任务文本进入 HTML 模板导致的注入风险。
- 桌面容器丢失时先清空状态、导致恢复失效的问题。
- 桌面挂接失败后仍不可聚焦、缺少任务栏入口的问题。
- 原生关闭窗口绕过待保存内容检查的问题。

## 数据兼容

支持原有四分区 Markdown。首次编辑后添加隐藏元数据，稳定保存任务身份和跨分区关系。同分区缩进仍可手工修改。说明文字、未知分区和围栏代码保留，但受管理分区会整理任务顺序。

默认正式数据文件不变；演示模式默认使用单独的临时目录。备份保留策略只作用于应用自己的备份目录。

## 验证范围

26 项自动化测试通过。在 Windows 11 上完成 NSIS 打包、应用启动、主题切换和实际落盘检查；桌面挂接调用返回成功。浏览器检查了 520×740 和 380×500 布局、添加、搜索、编辑、撤回与紧急筛选。

尚未完整验证多屏不同缩放、睡眠唤醒和资源管理器重启。本次已发布 Windows x64 安装包；上述场景仍需要更多设备反馈。
